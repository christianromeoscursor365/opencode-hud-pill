# opencode-hud-pill

GUI-плагин для OpenCode Desktop: в шапке сессии (рядом со счётчиком токенов) — HUD с погодой в Москве и живыми системными метриками: CPU%, температура/VRAM видеокарты, загрузка RAM, скорость сети (↓/↑ Мбит/с, как в диспетчере задач).

Формат: `⛅ 5° · CPU n% · VRAM t° / v% · 💾 m% · 🌐 ↓d ↑u Мбит/с`; недоступные блоки скрываются (значения `-1`).

- Погода — [MET Norway API](https://api.met.no/weatherapi/locationforecast/2.0/compact) каждые 15 минут (open-meteo и wttr.in в этой сети блокируются/зависают).
- Системные метрики GUI опрашивает каждые 5 секунд по RPC плагина: окно Electron не имеет доступа к nvidia-smi и счётчикам ОС, поэтому серверная часть (`index.js`) собирает их и отдаёт через `rpc-def.js`.

## Установка

Скопировать папку (или склонировать) в `~/.config/opencode/plugins/hud-pill/`, затем полностью перезапустить Desktop (`opencode service stop` + закрыть и открыть окно — хот-релоад GUI-бандла не работает).

Бандл `dist/gui-experimental.cjs` уже собран и закоммичен — пересборка не нужна.

## Сборка

```
npm install
npx vite build
```

Требования к окружению сборки описаны в `node_modules/@opencode/plugin` — хост загружает только `dist/gui-experimental.cjs`, собранный пресетом `@opencode/plugin/gui/vite`.

## Как это работает

- `Slot at:"session.header"` — `TitlebarItem` в Desktop 2.2.6 не рендерится вообще.
- `Slot.render` вызывается один раз, поэтому рендер возвращает persistent `<span>`, который обновляется через `createRenderEffect` (обычная строка замёрзла бы на «⏳ …»).
- GUI-часть (`src/gui.tsx`) не требует `id`; серверная часть `index.js` обязана его иметь (`"hud-pill"`), иначе плагин не грузится.
- Сеть — дельта счётчиков байтов адаптера из `netstat -e` между опросами (аналогично диспетчеру задач). Вывод `netstat` локализован, поэтому числа читаются позиционно (первая строка с двумя чисто-числовыми колонками), а не по подписям.
- Схема RPC (`rpc-def.js`) — общий JSON-Schema объект для сервера и GUI: ответ обработчика валидируется по `output`, расхождение формы = HTTP 500 на каждом опросе и молча скрытый блок в GUI.
